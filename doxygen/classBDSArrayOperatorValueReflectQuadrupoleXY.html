Detailed Description

Reflect field values for a quadrupole field in the positive quadrant.

Note this must work in combination with a coordinate reflection in x and y. Ultimately, the goal is this:

*       y
*       ∧
*       |
* <---  |  ∧
*    |  |  | original
*    v  |  --->
*       |
* -------------------> x
* <---  |     ∧
*    |  |     |
*    v  |  <---
*       |
*       |
*

Detailed Description

Integrator that ignores the field and uses the analytical solution to a solenoid.

Analytical solution to a solenoid field. This is implemented with some caveats - this is only really valid for one complete step through the solenoid. If this is used for a partial step, the edge focussing won't be correct. A work in progress.

Author
Laurie Nevay

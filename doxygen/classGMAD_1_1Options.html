Detailed Description

Options class.

Options passed with option command. This inherits the OptionsBase class which contains all the members and provides templated filling functions. This separation allows the OptionsBase class to be more easily written out to ROOT files or other formats for strong reproducibility in a BDSIM run.

Author
I. Agapov, J. Snuverink
